# WinsWi Super App1 — 5.1.1 consolidated source

Cette release est basée sur WinsWi 5.1.1 et consolide les deux spécifications fournies :
- Intelligence Engine / matching / trust / price / CRM / social
- Global Opportunity Engine / agrégation autorisée / déduplication / synchronisation / Social Ecosystem

## Important
Les intégrations externes sont conçues comme des adaptateurs légaux : aucune clé, scraping non autorisé ou contournement d'API n'est inclus.

## Validation
```bash
npm install
npm run verify
npm run typecheck
npm run lint
npm run build
```

Voir `docs/GOOGLE-AI-STUDIO-DEPLOYMENT.md` avant publication.
