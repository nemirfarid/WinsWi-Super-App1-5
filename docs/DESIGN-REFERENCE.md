# WinsWi Design Reference

The files in `docs/design-references/` are the user-provided visual references for the premium UI direction.

Target characteristics:
- deep navy / electric blue backgrounds;
- gold premium accents;
- mobile-first composition;
- rounded cards and glass panels;
- central WinsWi AI orb in the bottom navigation;
- universe-first discovery;
- premium but readable typography;
- adaptive light/dark/weather/time modes;
- FR / AR / EN and RTL support.

The references are design targets, not runtime assets. The implementation should remain responsive and accessible rather than embedding screenshots as UI.
