# WinsWi 4.0.0 — Professional + Voice + Ads

Cette version transforme la base WinsWi en produit orienté Super-App avec trois blocs supplémentaires réellement branchés :

- espace professionnel ImmoWin pour agence/promoteur ;
- CRM prospects/pipeline ;
- WinsWi Ads (campagnes, budgets, ciblage, événements) ;
- assistant vocal navigateur : Speech Recognition → `/api/ai` → Speech Synthesis ;
- historique des sessions vocales Supabase pour les utilisateurs connectés ;
- nouvelle identité visuelle bleu nuit / or, navigation mobile avec bouton IA central et responsive desktop ;
- FR/AR/EN pour le shell et RTL dynamique.

## Limite de validation

L'environnement de génération n'a pas terminé `npm install` malgré plusieurs tentatives. Cette release ne prétend donc pas être un build CI validé localement. La CI GitHub reste la source de validation finale.
