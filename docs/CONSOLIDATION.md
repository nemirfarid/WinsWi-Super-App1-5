# Consolidation WinsWi

## Règles
1. Ne pas déclarer une fonctionnalité réelle sans test.
2. Ne jamais simuler silencieusement un service externe.
3. Aucun secret dans Git.
4. L'IA Gemini reste côté serveur.
5. Les données demo sont marquées comme demo.
6. Les 7 univers partagent le design system mais gardent leurs modèles métier.
7. Toute fonctionnalité sensible nécessite authentification/autorisation.

## Priorités
P0: build/typecheck, auth, persistance, IA réelle, sécurité.
P1: messagerie, notifications, demandes/matching, médias, admin.
P2: Premium/paiements, offline sync, analytics, intégrations externes.
