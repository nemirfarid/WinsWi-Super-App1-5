# ImmoWin Pro / CRM

Tables Supabase : `crm_leads`, `crm_activities`.

Pipeline : nouveau → contacté → qualifié → rendez-vous → visite → négociation → gagné/perdu.

L'espace `/immowin/pro` est destiné aux agences, promoteurs et professionnels. Les permissions sont appliquées par RLS sur `owner_id`.
